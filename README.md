# Territory Framework

Add Places, guards, capture, income, diplomacy, counterattacks, and story rules to an Unreal game that uses Narrative Pro.

**Current version: 0.3.0-preview.1.** This is a community preview. Read the release notes before using it in a live game.

## Start here

1. Get the download for your Unreal version from [GitHub Releases](https://github.com/TaimoorSiddiquiOfficial/TerritoryFramework/releases).
2. Follow [Install and update](Docs/RELEASE_INSTALL.md). Narrative Pro is required and is installed separately.
3. Read the [easy guide](Docs/00_Easy_Complete_Guide.md), then the [quick start](Docs/01_Quick_Start.md).
4. In Unreal, hover over a setting or Blueprint function to see what it does. The [help guide](Docs/COMMUNITY_HELP.md) explains common words and numbers.

The downloads include Territory Framework and its example UI, AI, Definitions, dialogue, economy, road, and Tales assets. See [Included content](Docs/INCLUDED_CONTENT.md).

Narrative Pro is installed separately. The downloads do not include the TDA game map, its custom player appearance, its music packs, or the Brushify rock mesh.

See [version rules](Docs/VERSIONING.md), [release checks](Docs/RELEASE_VERIFICATION.md), and the [full guide index](Docs/README.md).
